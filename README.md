## Overview

This repository covers core NLP concepts and techniques, including:

- Text preprocessing
- Tokenization
- Sentiment analysis
- Named Entity Recognition (NER)
- Topic modeling

Implemented in Python using libraries like NLTK, spaCy, and scikit-learn.

Check the `notebooks/` directory for tutorials and examples.

```bash
cd notebooks
jupyter notebook
```
